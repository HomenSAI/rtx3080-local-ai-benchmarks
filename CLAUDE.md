## Release notes and changelog (owner's rule for all HomenS.AI repositories)

- Every entry of `CHANGELOG.md` and every GitHub release description is written **in English first**, and **the same text in Russian directly below it**. Layout of one entry:

  ```markdown
  ## 1.4.0 — 10 October 2026

  **English.** What changed, in plain words.

  - Detail one.

  **Русский.** То же самое по-русски, простыми словами.

  - Первая деталь.
  ```

- Both parts say the same thing; neither is shorter or adds facts. If the repository also keeps a Russian copy of the changelog (for example `docs/ru/CHANGELOG.md`), it holds the same bilingual entry in the same order.
- When a release is created on GitHub (by hand or by a workflow), its notes are this bilingual entry.
- Older entries are not rewritten; the rule applies from the next entry on.
